# Offline APTOS model

The APK expects the trained ONNX model at:

`frontend/assets/models/aptos_efficientnet_b0.onnx`

Generate it with:

```bash
python backend/ml/export_aptos_onnx.py \
  --checkpoint backend/models/aptos_efficientnet_b0.pt \
  --output frontend/assets/models/aptos_efficientnet_b0.onnx
```

The `.onnx` file is intentionally not generated by the source repository. It is produced from your trained APTOS checkpoint and then bundled into the Android/iOS app.
